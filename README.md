# gcdecode — 文法约束解码组件

给小语言模型的输出加上**文法约束**:每一步只允许选择"接在当前前缀后仍可能
得到合法结果"的词项,其余词项打分置为负无穷。纯 Python 标准库实现,无第三方依赖。

## 解决的问题

口述比赛记录经小模型转写后常出现缺括号、字段名拼错、分数写成文字等问题,
下游程序一解析就报错。本组件用一份文法在解码阶段强制输出合法结构。

## 快速开始

```bash
# 跑冰壶记录演示,生成可视化页面 reports/curling.html
python3 scripts/demo_curling.py
python3 scripts/demo_curling.py --open   # 生成后打开浏览器

# 全量正确性测试(约 15 秒)
python3 -m unittest discover -s tests -v
```

## 文法 DSL(类正则 + 递归规则)

规则必须以分号结束。支持:

| 结构 | 写法 | 说明 |
|---|---|---|
| 字面量 | `"abc"` `'x'` | 支持 `\n \t \xHH` 等转义 |
| 字符类 | `[a-zA-Z0-9 ]` `[^z]` | 取反类匹配未列出的任意字符 |
| 引用 / 递归 | `name` | 引用其他规则,支持右递归 |
| 选择 / 序列 | `a | b` / `a b c` | |
| 重复 | `e?` `e*` `e+` `e{n}` `e{n,m}` | |
| 嵌套对象 | `{"a": expr, "b": expr ?}` | `?` 标记可选字段,其余必选 |
| 数组 | `[expr]` | 零或多个,带界用后缀 |
| 枚举 | `#enum("RED" | "YEL")` | 几选一 |
| 整数范围 | `#int(0, 8)` | 无前导零的数字串 |
| 空白 | `#ws()` | 注入内置空白规则 |
| 注释 | `#` 开头的行 | 与 `#内置()` 区分 |

起始规则自动推断为引用图的汇点(不被其他规则引用、最后声明的规则),
也可用 `parse_grammar(text, start="name")` 显式指定。

## 架构

| 模块 | 职责 |
|---|---|
| `dsl.py` | 文法解析、脱糖(对象/枚举/范围展开为核心结构) |
| `automata.py` | Thompson NFA → 子集法 DFA → 划分细化最小化;规则引用编译为调用边 |
| `pda.py` | 带栈下推自动机、epsilon 闭包、接受/前缀两种活性分析 |
| `vocabulary.py` | 长短不一字符片段词表、trie、整数位图掩码 |
| `scorer.py` | 固定种子的确定性打分"小模型"(PCG 随机嵌入) |
| `decoding.py` | 贪心 / 温度采样 / 束搜索,逐词项掩码与计时 |
| `nfa_interp.py` | 独立暴力参考实现(递归下降前缀匹配,测试对照) |
| `randgen.py` | 随机文法与前缀生成 |
| `report.py` | 自包含 HTML 可视化报告 |

### 关键设计

- **DFA + 下推栈**:正则部分编译成最小化 DFA;规则引用不展开,而是作为
  调用边在运行时压栈/弹栈,因此支持任意嵌套与递归。
- **字符等价类**:全局字母表按出现字符划分类别,DFA 状态数与输入长度无关。
- **取反字符类**:编译为带排除集的通配边,子集构造按**逐 NFA 状态**判定,
  正确处理"一个状态走显式边、并行状态走通配边"的歧义。
- **两种活性**:
  - *前缀活性* = 还能再消费字符(普通词项掩码用,允许无基例尾递归的无限续写);
  - *接受活性* = 能走到完整终态(EOS 掩码用)。
- **掩码缓存**:无调用边的平坦规则按 DFA 状态预计算整座位图;带栈状态在线
  沿 trie 计算并按机器状态缓存,trie 子问题按 `(机器状态, trie 节点)` 记忆化。
- **跨符号词项**:trie 逐字符推进 PDA,一个词项跨多个文法符号或停在符号
  中间都能正确判定;必死子树整棵剪掉。
- **EOS 约束**:机器状态未到接受配置时结束符永不开放。

## 正确性保证(测试)

`tests/` 下 30 个测试覆盖:

1. **掩码等价**:40 种随机文法 × 2640 个前缀 × 84660 次逐词项判定,
   引擎掩码与独立暴力实现完全一致;
2. **解码接受性**:贪心 / 采样 / 束搜索产出都能被文法完整接受,所有束
   始终是合法前缀;
3. **最小化语言等价**:数千随机串上最小化前后 DFA 接受结果相同;
4. **EOS 纪律**:未写完不开放、接受态必开放;
5. 跨符号词项、取反字符类歧义、左递归拒绝、整数范围分支不被错误合并等边界。

暴力实现与自动机代码路径完全独立(直接在 AST 上递归下降),因此两者
一致才有对照意义。
